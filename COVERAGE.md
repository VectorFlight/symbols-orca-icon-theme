# Coverage

Generated by `scripts/build.mjs` from [Symbols](https://github.com/miguelsolorio/vscode-symbols) 0.0.25, commit [`a405d32`](https://github.com/miguelsolorio/vscode-symbols/tree/a405d32cca082d838ad7739b6d0044dea9dbbb79).

Orca allows at most 512 mappings in one icon theme. Symbols maps 1645 file names, extensions and folder names (counting the language ids it maps, turned into the extensions and file names VS Code gives them), so this port keeps 512:

- the generic file and folder icons;
- the common names listed in `scripts/priority.json`;
- at least one name for every other Symbols icon;
- then more names, a round at a time across all icons, until the budget runs out.

Every icon uses the SVG from Symbols. 320 of the 320 icons Symbols maps appear here.

A name left out below shows the generic file or folder icon instead. To change what is kept, edit `scripts/priority.json` and rebuild.
